Vérification des modules
Qui peut faire quoi
AdministrateurNomme les autres administrateurs et déclare un module vérifié. Le premier inscrit du poste l'est ; il y en a toujours un.
MembreCrée ses notes et ses projets ; ses initiales les signent.
Module vérifiéUn administrateur a relu sa méthode : on s'en sert sans la revérifier — chaque note reste à relire par son auteur. Si le calcul du module change, la marque tombe : il est à revérifier.
Où est enregistrée l'équipe ?

Pour l'instant, l'équipe et le journal sont enregistrés dans ce navigateur, comme les notes : chaque poste a les siens — les rôles et les modules vérifiés aussi. Les initiales d'une personne voyagent avec ses notes (le fichier .stab les porte). Les invitations par e-mail, les mots de passe et le partage entre les postes viendront avec les comptes du bureau.
