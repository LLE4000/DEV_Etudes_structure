# E04 — ELS, ELU et efforts par ancrage

## 1. Le passage ELS → ELU du classeur
C71/C70 = 68.9 / 42.76 = 1.61132 ; N_ELU = ρ·N_ELS = 22.9667 kN (C85), V_ELU = 22.9667 kN (C86) ; valeurs tapées à côté : G85 = 24,68 kN, G86 = 22,97 kN
Avec γG = 1,35 et γQ = 1,50 appliqués aux MÊMES charges caractéristiques, le rapport ELU/ELS caractéristique est compris entre 1,35 (tout permanent) et 1,50 (tout variable) :
   G/(G+Q) = 1.00 → ELU/ELS = 1.3500
   G/(G+Q) = 0.75 → ELU/ELS = 1.3875
   G/(G+Q) = 0.50 → ELU/ELS = 1.4250
   G/(G+Q) = 0.25 → ELU/ELS = 1.4625
   G/(G+Q) = 0.00 → ELU/ELS = 1.5000
Le rapport du classeur, 1.6113, dépasse 1,50 : 68,9 kN ne peut pas venir de 42,76 kN par les coefficients de l'EN 1990 (6.10) sur les mêmes charges. Les deux réactions viennent de calculs ou de combinaisons différents.
   si 42,76 kN était une combinaison fréquente (ψ1 = 0,5) : il faudrait G/Q = 2.657 pour retrouver 68,9 kN
   si 42,76 kN était une combinaison quasi permanente (ψ2 = 0,3) : il faudrait G/Q = 3.890 pour retrouver 68,9 kN
